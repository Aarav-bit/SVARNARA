## 2026-08-01 - [Prevent Default Scroll on Custom Buttons]
 **Learning:** [When using custom UI elements with `role="button"` and `onKeyDown` handlers (such as for opening a modal or lightbox), pressing 'Space' or 'Enter' will trigger the action, but 'Space' specifically can also cause the browser to scroll down the page if default behavior is not prevented. This creates a disorienting experience for keyboard users.]
 **Action:** [Always call `e.preventDefault()` inside `onKeyDown` handlers for custom buttons when the 'Enter' or 'Space' key is pressed to prevent unintended browser default behaviors like scrolling.]
